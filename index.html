Réglages

Un repo absent de la liste mais du même owner apparaît en bas, marqué « hors liste ». Liste vide : tous les repos s'affichent.

Recommandé : un token fine-grained en lecture seule, limité à ton compte (créer le token, permissions déjà remplies). Il vise l'owner du premier repo de la liste ci-dessus. Sur GitHub, il ne reste qu'à choisir « All repositories ». Si l'org exige une approbation, le token ne voit rien tant qu'un admin ne l'a pas validé.

Plan B, si les checks restent vides avec ce token : un token classique avec les scopes repo et read:org (créer le token). Si l'org impose le SSO, clique ensuite sur « Configure SSO » à côté du token.
